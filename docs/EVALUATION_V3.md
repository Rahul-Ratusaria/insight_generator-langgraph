# Real-document evaluation rubric

This project must be benchmarked with a privately approved corpus before claiming production readiness. Label at least 30 heterogeneous pages: simple tables, nested headers, graphics, heatmaps, images and scanned layouts.

**Measured targets to report:** numerical extraction precision and recall, page citation precision, wrong-column rate, arithmetic exactness, unsupported numerical claim rate, actionable insight usefulness (expert-scored), cost per page, and manual review workload.

Never equate the raw number of extracted cells or generated insights with decision quality. A wrong column association is worse than a missing fact. Record errors with document/page, expected value, actual value, table scope, and suspected root cause.
